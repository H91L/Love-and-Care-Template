# Love-and-Care-Template
# ❤️ warm_heart

一个温馨的桌面小程序合集——用弹窗拼成爱心，给身边的人一份小小的惊喜。支持 Python（tkinter）和网页（HTML）两种形式。

## 📁 项目结构

```
warm_heart/
├── heart.py                      # ⭐ 主程序：便签从中心飞出汇聚成爱心
├── warm_heart.html                 # 浏览器版：CSS动画爱心 + 点击绽放
├── 3d_hand_particle_heart.html           # 进阶版：Three.js 3D粒子 + 摄像头手势交互
├── dist/
│   └── warm_heart.exe              # heart.py 打包好的 Windows 可执行文件
└── README.md
```

## 🚀 快速开始

### 运行 Python 版

```bash
# 需要 Python 3.6+，内置 tkinter（通常自带）
python heart.py
```

### 运行网页版

直接用浏览器打开 `warm_heart.html` 或 `3d_hand_particle_heart.html` 即可。

### 打包为 EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name warm_heart heart.py
```

## 🎬 动画流程

### Python 版（heart.py）

```
┌──────────────┐    点击"好的"    ┌──────────────────┐    完成    ┌──────────────┐
│  前置弹窗     │ ──────────────→ │  30个便签窗口      │ ────────→ │  暖心寄语     │
│ "每天都要      │                │  从中心飞出，沿      │           │  随机寄语     │
│  开心点！"    │   点击"不要"     │  爱心轮廓排列       │           │  点击退出     │
│               │ ←────────────── │                    │           │              │
│  [好的][不要] │   换劝说文案     │  ❤️ 形状定格       │           └──────────────┘
└──────────────┘   按钮随机跑位   └──────────────────┘
```

- **爱心轮廓**：使用经典参数方程 `x=16sin³(t), y=13cos(t)-5cos(2t)-2cos(3t)-cos(4t)` 生成
- **飞行动画**：ease-out 缓出曲线（开始快、末尾吸附），约 4~5 秒全部到位
- **30 种配色**：粉红、浅蓝、浅绿、鹅黄、薰衣草紫等粉彩色系
- **30 条暖心文案**：随机分配，每张便签一句话

### 网页版（warm_heart.html）

纯 CSS + JavaScript 爱心动画，点击屏幕爱心粒子绽放，适合分享链接。

### 3D 手势版（3d_hand_particle_heart.html）

基于 Three.js + MediaPipe 手势识别：
- 🖐️ **张开手掌** — 粒子散开
- ✊ **握拳** — 粒子聚成爱心
- ✌️ **比耶** — 显示文字

> 需要浏览器开启摄像头权限。

## 🛠️ 技术栈

- **Python 版**：`tkinter`（Python 标准库，无需额外安装）
- **网页版**：HTML5 + CSS3 + JavaScript
- **3D 版**：Three.js + MediaPipe Hands
- **打包**：PyInstaller

  开始窗口：屏幕中央弹出"温馨提醒"窗口，浅蓝底色，上方显示"每天都要开心点！"，下方并排两个按钮——绿色"好的"和珊瑚色"不要"   。点击"不要"文字会换成撒娇劝说语（"别这样嘛~""再想想？"等），按钮随机跳位。点击"好的"窗口消失，动画启动。    动画核心：30 个彩色 Toplevel 小窗（粉红、浅蓝、浅绿、鹅黄等 30   种粉彩色），各有不同暖心文案，从屏幕中心逐个飞出，沿直线飞向各自在爱心轮廓上的位置——开始快、末尾缓停，约 4~5   秒全部到位，最终在屏幕中央定格成一颗 ❤ 形。    结束窗口：关闭爱心后弹出"暖心寄语"窗口，奶白底色红字，随机显示一段关怀寄语（如"愿你三冬暖，愿你春不寒，愿你天黑有灯，   下雨有伞"），点击任意位置或 X 按钮整程序退出。
